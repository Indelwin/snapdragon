name: release-check
description: Prepare a package release by checking versions, changesets, packing, and smoke tests.
tags: [release, npm, packaging]
---

Audit the repo for release readiness.

Check:
- Changesets exist for public package changes.
- Package metadata is anonymous and intentional.
- Build outputs are generated by the package scripts.
- `npm run pack:dry` includes required runtime assets and excludes secrets.
- Local import-cycle smoke tests cover the shipped package entrypoints.
- No tokens, auth files, or private paths are committed.

Run the release gates configured by the repo. Do not publish unless the user explicitly asks for publishing.
